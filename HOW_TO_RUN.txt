EE641 Chess PPO milestone evaluation patch

1. Extract this ZIP into B:\EE641_Chess_RL_Starter\ and replace run.cmd.
   This adds chess_rl\ppo_milestone_eval.py and tests\test_ppo_milestone_eval.py.
   Do NOT delete or replace any other project folders or checkpoint files.

2. In CMD inside B:\EE641_Chess_RL_Starter, run:

      run.cmd ppo-milestone-smoke

   The smoke test plays the 3 new milestone checkpoints against Maia1900
   from two reserved October openings (12 games). It also runs unit tests.

3. If that works, run:

      run.cmd ppo-milestone-eval

   The full evaluation plays 50k/75k/100k against Maia1900 on 256 matched
   October opening pairs (1,536 new games). It reuses the original V0 and S49
   confirmation games after verifying their checkpoint and engine hashes.
   These existing games must be complete. No training takes place.

4. To display the saved results later:

      run.cmd ppo-milestone-report

NEW outputs appear at:
  outputs\ppo_milestones_oct2026_manifest.json
  outputs\ppo_milestones_oct2026_games.jsonl
  outputs\ppo_milestones_oct2026_summary.json
  outputs\ppo_milestones_oct2026_learning_curve.csv

All original October confirmation results and model checkpoints are read-only.
If the process is interrupted, rerun the same command to resume saved games.

Research note: This is an exploratory learning-curve comparison on the
previously used October opening set, not a fresh confirmatory significance
study. The Maia opponent uses one-node Lc0 policyhead, not a search baseline.
A true Stockfish search baseline can be added separately later.

Validation: Python source and test files were syntax-checked here. Complete
runtime tests require your original project files, checkpoints, Maia assets,
and installed dependencies on your computer.
